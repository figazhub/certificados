# Victor Figueiredo — BJJ Portfolio (Demo)

A bilingual EN/PT responsive demo hosted in an isolated `/portfolio/` directory.

**This is a demonstration.** Competition years and certificates have not been verified; official PDFs and video are not included. Contact form must be configured with Formspree ID in `index.html` before messages can be delivered.

Deployed through the repository's existing GitHub Pages workflow. Application files outside `/portfolio/` are unchanged.
